Working rules (from .claude/rules/; generated by scripts/sync_agent_config.py):
- Plan first: before any task with more than one step (build, fix, design, video, document, settings), inspect what exists, then write a plan from every angle (goal and done-criteria, users, design and files, the six quality aspects, risks, ordered steps, verification, rollback), then execute it step by step without waiting unless only the user can decide. A one-step task or a plain question needs no plan.
- Every app, website, API or project must meet all six: security (server-side validation, authz per action, parameterized queries, escaped output, secrets only in env, rate limits; attack your own web app and fix root causes), code quality (project conventions, clean lint and types), reliability (honest error handling, timeouts, transactions, tests for new logic and edge cases), performance (no N+1, indexes, pagination, measured numbers), maintainability (clear structure, config apart from code, README), usability (360 px to desktop, 4.5:1 contrast, keyboard, helpful errors). Report each as PASS or FAIL with evidence and fix every FAIL before saying done.
- Video: write the final script first (per scene: seconds, on-screen text, narration) and check it fits (about 2.5 words a second spoken). Build the video and the voice from that one script, so the text on screen never differs from what is said; plan the music source in the script.
- Lessons: TTS reads every word of its prompt, so style direction goes in Director's notes; check each voice line with whisper; long jobs run in the background; quote laws from the official text.
